## 🚀 Quick Start Guide

### 1. Setup (5 minutes)
```bash
# Backend setup
cd backend
npm install
cp .env.example .env
# Edit .env with your database details

# Database setup
mysql -u root -p
CREATE DATABASE grocery_delivery_db;
SOURCE ./database/schema.sql;

# Start backend
npm run dev
```

### 2. Run Frontend
- Open `frontend/index.html` in browser
- Or use VS Code Live Server
- Or use `python -m http.server 8000`
